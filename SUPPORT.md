# Support

## Usage Questions

Use [GitHub Discussions](https://github.com/sarathkumar1207/software-brain-engine/discussions)
for installation help, command usage, design questions, and general troubleshooting.

Before asking for help:

1. Read the [README](README.md) and documentation under [`docs/`](docs/).
2. Run `sbe doctor <path>` when the problem involves an existing index.
3. Search existing discussions and issues.
4. Include the SBE version, operating system, installation method, command, and sanitized output.

Use a bug report only when behavior is reproducibly incorrect. Report security vulnerabilities
privately according to [SECURITY.md](SECURITY.md).

Community support is best-effort. There is no guaranteed response time or commercial support
commitment.

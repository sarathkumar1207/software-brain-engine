Install

Install once, run from any terminal.

Windows

Download the MSI from GitHub Releases and install it like a normal developer tool.

sbe-0.2.0-windows-x64.msi

macOS and Linux

Download the platform archive and place the native binary on your PATH.

sbe-linux-x64.tar.gz

Developers

Install from source while developing the project.

cargo install --path crates/cli --force
